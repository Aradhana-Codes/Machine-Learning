# Machine Learning Algorithms

This repository contains the implementation of various Machine Learning algorithms along with their source code and datasets. It covers data preprocessing, model training, evaluation, and practical examples using Python and Scikit-learn.

## Learning Reference

The implementations in this repository are developed as part of my Machine Learning learning journey, following concepts and tutorials from **CampusX**. Some implementations are based on or inspired by the code demonstrated in their tutorials.

I have recreated and practiced these implementations on my own environment to understand the underlying concepts and workflow.
